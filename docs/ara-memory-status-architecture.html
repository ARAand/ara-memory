Ara Memory OS 현재 작업 상황과 아키텍처

26시간째 제작 중인 현재 시스템은 단순 벡터DB가 아니라 원문 증거, 압축 기억, 작업 기억, 관계 그래프, 승인형 변경, 백업과 회귀검사를 함께 가진 로컬 우선 장기기억 운영체제다. 아직 완성은 아니다. 지금의 핵심은 "많이 저장"이 아니라, 나중에 필요한 맥락만 싸게 되살리고 잘못된 기억 변경을 되돌릴 수 있게 만드는 것이다.

현재 완성된 부분

  • 프롬프트, 응답 요약, 파일/이미지 설명, 명령 결과, 의사결정을 source event로 수집한다.
  • 원문 증거는 보존하고, 검색/추론용 capsule은 별도로 압축해 토큰 낭비를 줄인다.
  • hot memory, working memory, cold memory, distant memory map을 분리했다.
  • 목표, 정체성, 절차, 실패, 프로젝트 증거를 다른 kind로 분류한다.
  • 관계 그래프와 FTS를 함께 사용해 벡터DB 없이도 맥락 후보를 좁힌다.
  • doctor, health, milestone, recall-regression, privacy-pre-push로 운영 게이트를 만들었다.
  • 백업, 검증, restore drill, cold export, retention cycle로 장기 보존 경로를 만들었다.
  • review-worker와 rollback witness로 자동 변경을 추적하고 되돌릴 수 있게 했다.

최근 단계

  • mutation-preflight가 rewrite/delete 전 before/after/rollback projection과 risk gate를 만든다.
  • prepare-mutation은 통과한 preflight만 짧은 수명의 one-use token으로 승인한다.
  • live-mutation-apply는 rewrite와 soft-delete에 대해 drift check, token check, confirmation check를 통과해야만 실제 반영한다.
  • prepare-mutation-rollback과 live-mutation-rollback은 적용된 rewrite witness를 되돌린다.
  • delete는 물리 삭제가 아니라 APPLY MEMORY SOFT DELETE 확인문을 요구하는 rejected 상태 전환으로만 열린다.
  • review queue는 compact/review-worker 경로로 관리되고, 자동 적용은 witness를 남긴다.
  • working-memory impact eval이 기억 호출이 실제 작업에 도움인지 방해인지 평가한다.

아키텍처

1. Capture대화, 파일, 이미지, 명령, 결정, 실패를 event envelope로 받는다. 숨은 추론은 저장하지 않고 검토 가능한 요약과 증거만 저장한다.
2. Guard비밀, 직접 생계형 개인정보, 위험 문자열, 저장 금지 항목을 redaction 또는 block 처리한다.
3. Storesource event는 원문 증거로, capsule은 압축 기억으로, relation은 연결 단서로 따로 저장한다.
4. Compress반복 작업 로그를 목표, 결정, 절차, 실패, 프로젝트 증거 단위로 접어 토큰 비용을 줄인다.
5. Recall현재 목표와 질문에 맞는 hot/working/cold 후보만 뽑고, 필요한 경우 source link로 원문까지 거슬러 올라간다.
6. Mutate기억 변경은 preflight, approval token, drift check, witness, rollback 게이트를 통과해야 한다.

판단

  • 동작 현재 저장, 압축, 회상, 백업, health gate는 정상이다.
  • 부족 자연스러운 기억의 핵심인 "잊기/왜곡 방지/상황별 회상"은 아직 운영 루프가 약하다.

현재 목적성

이 기억의 목적은 모든 원문을 매번 읽는 것이 아니다. Jongseo와 Ara가 이어서 만들던 맥락, 판단, 실패, 선호, 설계 이유를 작은 회상 단위로 되살려서 Codex가 매번 새로 태어난 도구처럼 굴지 않게 하는 것이다. 따라서 저장소는 "기록 보관소"이면서 동시에 "회상 정책을 가진 인지 구조"여야 한다.
