아키텍처

1. Capture프롬프트, 응답, 파일, 이미지 설명, 명령 결과, 결정, 실패를 event envelope로 받아들인다.
2. Guard비밀, 직접 식별자, 위험 텍스트, 저장 금지 항목을 redaction 또는 block 처리한다.
3. Store원문 증거는 ledger/archive에 남기고, 검색용 capsule과 graph는 별도 구조로 저장한다.
4. Compress원문을 통째로 반복 투입하지 않고 목적, 결정, 실패, 작업 맥락 단위로 압축한다.
5. Recall현재 목표에 맞는 capsule, source link, distant memory만 제한된 토큰 예산으로 불러온다.
6. Gate기억 변경은 prepare, review, approval, witness, rollback, backup 검증을 통과해야 한다.
