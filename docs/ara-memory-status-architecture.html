Ara Memory OS 현재 작업 상황과 아키텍처

현재 시스템은 26시간 이상 제작 중인 장기 기억 저장소다. 목표는 원문 전체를 매번 다시 읽는 구조가 아니라, 목적, 정체성, 결정, 실패, 작업 맥락, 망각 경계를 분리하고 필요한 맥락만 작게 불러오는 자연스러운 기억 구조다. 이번 단계에서는 live rollback gate 위에 exception witness를 붙여, 의도된 증거 변화와 위험한 drift를 구분할 수 있게 했다.

완료된 축

  • 로컬 우선 저장소: SQLite, ledger, capsule, FTS, relation graph.
  • 상시 입력 경로: remember-turn, spool-turn, drain-spool.
  • 토큰 절감 recall: raw 전체 읽기 대신 capsule projection, recall-policy, working-memory pack.
  • 수명주기 분리: core, working, guarded, evidence, archive, reject.
  • 품질/안전 게이트: doctor, health, milestone, goal-roadmap, privacy-pre-push.
  • candidate-only 재통합: prepare, apply, review, strong shadow preflight, rollback gate.

이번 단계

  • SCHEMA_VERSION을 19로 올리고 reconsolidation_exception_witnesses를 추가했다.
  • reconsolidation-exception-witness가 witness id, capsule id, field, reason, before/after digest를 저장한다.
  • review와 rollback은 기록된 field와 정확히 같은 digest transition만 허용한다.
  • 다른 edit이나 두 번째 drift는 계속 차단된다.
  • goal-roadmap은 exception witness gate를 별도 항목으로 표시한다.

현재 리스크

  • 강한 재통합은 아직 live capsule promote/supersede/rewrite/delete/cool 권한을 갖지 않는다.
  • rollback은 live gate까지 열렸지만, 범위는 witness 하나의 candidate frame rejection으로 제한된다.
  • exception witness는 설명 장치일 뿐 권한 상승 장치가 아니다.
  • semantic hygiene false failure는 재분류했고 milestone readiness는 pass다.
  • roadmap의 남은 watch 항목은 reconsolidation rollback review queue 1건이다.
  • API 기반 AI memory worker는 아직 기본 경로가 아니다. 현재는 로컬 deterministic gate가 중심이다.

아키텍처

1. Capture프롬프트, 파일, 이미지, 명령, 결정, 결과를 event 또는 turn envelope로 저장한다.
2. Guard비밀, 직접 식별자, hidden reasoning, 위험 텍스트를 저장 전 redaction 또는 차단한다.
3. Store원문 증거는 ledger/archive에 두고, 검색용 capsule과 graph는 SQLite/FTS로 분리한다.
4. Recall목적, 작업, distant memory, retention intent를 분류하고 작은 context pack만 렌더링한다.
5. Gateprepare/apply/review/queue/rollback/exception/health가 강한 기억 변형 전 증거를 검증한다.

다음 판단

  • 즉시 강한 live mutation을 열면 빠르지만 위험하다.
  • 다음 1순위는 reconsolidation rollback review queue의 watch 항목을 해소하는 것이다.
  • 그 다음 strong reconsolidation action을 preflight/rollback/exception gate에 연결해야 한다.
  • AI API 비용은 기본 경로가 아니라 optional batch summarizer로 제한하는 편이 낫다.
  • 이 기억의 목적은 더 많은 저장이 아니라, 원하는 맥락만 자연스럽게 떠오르게 하는 것이다.
